# 큰사전 원고 지킴이

초등 국어 6-2 4단원 「큰사전이 필요하다」(194~203쪽)를 위한 걸어 다니는 3D 체험 페이지입니다.

- **1차시**: 1910~1945년 시간 여행 장면 6개 — 장면마다 교과서 쪽을 먼저 읽고 활동해요.
- **2차시**: 1957년 『큰사전』 완간 기념관의 방 4개 — 연표와 추론 활동을 해요.

교과서를 대신하지 않고, 차시 도입·정리 때 함께 쓰도록 만들었어요.

## 사용법

- 크롬북·PC 브라우저에서 페이지를 열면 바로 시작돼요. 설치나 로그인은 필요 없어요.
- 진행 기록은 그 기기의 브라우저에 저장돼요. 같은 아이는 같은 기기로 하고, 게스트 모드는 쓰지 마세요.
- 움직이기: 방향키·WASD 또는 화면 버튼, 점프 Space, 달리기 Shift.

## 파일
